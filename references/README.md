# References

The guides refer to two unofficial study resources for MVA Robotics 2026:

- **MVA Robotics 2026 Notes** (`MVA_Robotics_2026_Notes.pdf`): explanations and examples for lectures 2–7.
- **MVA Robotics 2026 Practice Quiz** (`MVA_Robotics_2026_Practice_Quiz.pdf`): topic-by-topic multiple-choice questions with answers.

These PDFs are shared separately and are not included in the repository. If you have access, place your copies in this folder; Git ignores these filenames. Ask the author for access or permission to redistribute them.

Both resources are unofficial and omit the introductory lecture. Some statements need qualification: see the relevant topic guides for corrections. Page references use PDF viewer page numbers.
